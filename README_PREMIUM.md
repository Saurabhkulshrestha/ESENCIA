# ESEN’CIA Premium Ecommerce Prototype

This version is a front-end ecommerce experience using the supplied ESEN’CIA product photography.

## Working features
- Responsive premium skincare storefront
- Homepage, shop, dynamic product pages
- LocalStorage shopping bag with quantity controls and remove
- Demo checkout flow
- 3-question serum finder
- Product search modal
- Product image galleries
- Concern filters
- Mobile responsive layout

## Important production gaps
This is intentionally a deployable front-end prototype, not a live payment-enabled store. Before launch, connect an ecommerce backend/payment provider and replace demo checkout behavior.

Still required from the brand/business side: approved retail prices, SKU/UPC/GTIN, complete final INCI lists, approved directions/warnings, legal company/contact information, shipping/returns policy, privacy/terms, verified claims substantiation, final Amazon attributes, analytics, SEO metadata, inventory/fulfillment and payment configuration.
